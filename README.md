# Tidewatch

A contraction timer prototype for labor. It times contractions, names the phase (early, active, transition) and estimates when to leave for the hospital using the 5-1-1, 4-1-1 or 3-1-1 rule.

Single static file (`index.html`), no build step. Data stays in the browser's local storage.

Prototype only. Not medical advice. Follow your provider's instructions.
